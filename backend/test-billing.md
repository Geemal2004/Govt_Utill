# Billing API Testing Guide

## Prerequisites
1. Server running on `http://localhost:3001`
2. Valid JWT token from login (see `test-auth.md`)
3. Database with sample data from `SQL.sql`

---

## 🔐 Step 1: Get Authentication Token

```powershell
# Login as Admin Staff (EMP-ADM-001)
$loginResponse = Invoke-RestMethod -Uri "http://localhost:3001/api/auth/login" -Method POST -ContentType "application/json" -Body '{"employee_no": "EMP-ADM-001"}'

# Extract token
$token = $loginResponse.token
Write-Host "Token: $token"
```

## 📊 Step 2: Test Billing Endpoints

### 2.1 Generate Bill (POST /api/billing/generate)

**Note:** Requires ADMIN or MANAGER role

```powershell
# Generate bill for connection_id = 1
$headers = @{
    "Authorization" = "Bearer $token"
    "Content-Type" = "application/json"
}

$body = @{
    connection_id = 1
    bill_date = "2025-12-02"
} | ConvertTo-Json

$billResponse = Invoke-RestMethod -Uri "http://localhost:3001/api/billing/generate" -Method POST -Headers $headers -Body $body
```

## 🧪 Test Scenarios

### Scenario 1: Complete Billing Workflow

```powershell
# 1. Login as Manager
$manager = Invoke-RestMethod -Uri "http://localhost:3001/api/auth/login" -Method POST -ContentType "application/json" -Body '{"employee_no": "EMP-MG-041"}'
$managerToken = $manager.token
$managerHeaders = @{
    "Authorization" = "Bearer $managerToken"
    "Content-Type" = "application/json"
}

# 2. Generate bill for a connection
$newBill = @{
    connection_id = 3
    bill_date = "2025-12-02"
} | ConvertTo-Json

$generated = Invoke-RestMethod -Uri "http://localhost:3001/api/billing/generate" -Method POST -Headers $managerHeaders -Body $newBill

# 3. Check unpaid bills
$unpaid = Invoke-RestMethod -Uri "http://localhost:3001/api/billing/unpaid" -Headers $managerHeaders

# 4. Generate defaulters report
$defaulters = Invoke-RestMethod -Uri "http://localhost:3001/api/billing/defaulters" -Headers $managerHeaders

Write-Host "✅ Billing workflow completed successfully"
```

### Scenario 2: Test Role-Based Access Control

```powershell
# Login as Meter Reader (non-admin role)
$reader = Invoke-RestMethod -Uri "http://localhost:3001/api/auth/login" -Method POST -ContentType "application/json" -Body '{"employee_no": "EMP-MR-011"}'
$readerToken = $reader.token
$readerHeaders = @{
    "Authorization" = "Bearer $readerToken"
    "Content-Type" = "application/json"
}

# Try to generate bill (should fail with 403 Forbidden)
try {
    $failBill = @{
        connection_id = 5
    } | ConvertTo-Json
    
    Invoke-RestMethod -Uri "http://localhost:3001/api/billing/generate" -Method POST -Headers $readerHeaders -Body $failBill
    Write-Host "❌ ERROR: Should have been forbidden!"
} catch {
    Write-Host "✅ Correctly forbidden: $($_.Exception.Message)"
}

# Can view unpaid bills (should succeed)
$unpaidView = Invoke-RestMethod -Uri "http://localhost:3001/api/billing/unpaid" -Headers $readerHeaders
Write-Host "✅ Can view unpaid bills: $($unpaidView.results) bills found"
```

## 🐛 Troubleshooting

### BigInt Serialization Error
If you see: `TypeError: Do not know how to serialize a BigInt`

**Solution:** The global BigInt.toJSON patch in index.ts should handle this. Restart the server.

### Token Expired
```powershell
# Get a fresh token
$loginResponse = Invoke-RestMethod -Uri "http://localhost:3001/api/auth/login" -Method POST -ContentType "application/json" -Body '{"employee_no": "EMP-ADM-001"}'
$token = $loginResponse.token
```

### Stored Procedure Not Found
Check that `sp_GenerateBillForConnection` and `sp_ListDefaulters` exist in your database:
```sql
SELECT * FROM sys.procedures WHERE name LIKE 'sp_%'
```
